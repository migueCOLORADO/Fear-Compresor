ENTREGA: compresor/descompresor Huffman concurrente para el editor
==================================================================
Estado: incluye las correcciones de la revisión (sin rwlock, cancelación
atómica, progreso monótono, pruebas bajo ThreadSanitizer).

Contenido:
  nuevos/        -> archivos que NO existían en el repo (cópialos tal cual).
  modificados/   -> archivos del repo original con cambios mínimos y aditivos.
  huffman-concurrente-vs-main.patch -> TODO en un parche contra 'main'.

Aplicar el parche (recomendado), desde la raíz del repo:
  git checkout -b feat/huffman-concurrente
  git apply huffman-concurrente-vs-main.patch     # o: patch -p1 < ...
  (si prefieres crear commit: git add -A && git commit)

Compilar y probar (desde editor/):
  make            # editor con -pthread, limpio con -Wall -Wextra -Werror
  make test       # 66/66 (pruebas existentes del editor)
  make test-huf   # suite Huffman (corrección, carreras, cancelación, errores...)
  make test-asan  # suite bajo AddressSanitizer/UBSan/LeakSanitizer
  make test-tsan  # suite bajo ThreadSanitizer
Desde shell/:
  make            # eafitOS con la categoría editor + compresor

Nota: make test-asan/test-tsan requieren las libs de sanitizers del compilador.
